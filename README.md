# Merge Bazaar — web version

The Telegram Mini App build of **Merge Bazaar**, a Silk Road merge game by Sayro Games.

Play in Telegram: https://t.me/Sayrogamesbot/mergebazaar

These files are made by Unity (Merge Bazaar > Build Telegram (WebGL)) and served by GitHub Pages.
To update the game, replace everything here with the new contents of `Builds/Telegram` and push.
